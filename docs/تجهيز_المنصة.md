---

## 1. الفلسفة المعمارية ونظام التخصيص الفردي (White-Label Philosophy)

منصة `edu_saas` مبنية كمنصة **White-Label Multi-Tenant**. كل مدرس أو مركز تعليمي يمثل مستأجراً مستقلاً (`Tenant`). 
تتميز المنصة بـ **محرك هوية ديناميكية (Dynamic Branding Engine)** مدمج في الكود، يتيح للمنصة أن تتغير كلياً وبشكل لحظي لتطابق هوية المدرس:
1. **الألوان والتدرجات:** توليد تلقائي للوحة ألوان فخمة، وظلال ميكروية، وتدرجات أزرار وشاشات بدون كسر الـ Design Tokens.
2. **الرموز الأكاديمية والشعار:** دعم العلامات المائية للرموز الرياضية ($\sum, \int, f(x), \pi, \Delta$) أو شعار المدرس المخصص.
3. **الترويسة والأشرطة الجانبية:** تعرض تلقائياً اسم أكاديمية المدرس، ومساره الدراسي، ونصوص الترحيب الخاصة به.

## 2. البيانات المطلوبة من المدرس الجديد (Teacher Profile Intake Form)

عند رغبة مدرس جديد في تشغيل المنصة له، اطلب منه تعبئة البيانات التالية:

| الحقل | الوصف والمثال | الحالة |
|---|---|:---:|
| **اسم المدرس الأكاديمي** | مثل: `أ. محمد عبد الرازق` أو `د. حازم القاضي` | إلزامي |
| **اسم المنصة / الأكاديمية** | مثل: `أكاديمية الفارس للرياضيات` أو `Apex Math Academy` | إلزامي |
| **المادة والمسار الدراسي** | مثل: `رياضيات النظام الأمريكي • SAT / EST / ACT` أو `ثانوية عامة` | إلزامي |
| **الشعار اللفظي (Slogan)** | مثل: `الطريق الأقصر نحو الدرجة النهائية 800/800` | إلزامي |
| **اللون الرئيسي المميز (Primary Color)** | كود HEX مثل: `#1E3A8A` (كحلي نيلي) أو `#059669` (أخضر زمردي) أو `#7C3AED` (بنفسجي ملكي) | إلزامي |
| **الرمز الأكاديمي المميز** | مثل: `∑` (سيجما) أو `∫` (تكامل) أو `f(x)` أو `Δ` (دلتا) | اختياري (الافتراضي `∑`) |
| **ملف الشعار (Logo)** | رابط URL أو صورة PNG/SVG مفرغة | اختياري |
| **صورة المدرس الشخصية (Avatar)** | صورة شخصية احترافية لاستخدامها في البانر الترحيبي | اختياري |
| **بيانات التواصل والدعم** | رقم واتساب، هاتف، أو بريد الدعم الأكاديمي | اختياري |
| **المجموعات الدراسية المبدئية** | قائمة المجموعات (مثل: `Basics`, `SAT 1 Morning`, `EST 2 Evening`) | إلزامي |

## 3. خطوات التنفيذ البرمجي (AI Step-by-Step Execution Guide)

### الخطوة 2: إضافة صور وشعار المدرس (إن وُجدت)

1. إذا قدم المدرس ملف شعار (`logo.png`) أو صورته الشخصية (`teacher.png`):
   - ضع الملفات داخل المجلد: `assets/branding/`
2. تأكد من إدراج المجلد في `pubspec.yaml` تحت قسم `assets:`:
   ```yaml
   flutter:
     assets:
       - .env
       - assets/branding/
   ```
3. في كود `TenantBranding`:
   ```dart
   logoAsset: 'assets/branding/logo.png',
   avatarUrl: 'assets/branding/teacher.png',
   ```

## 5. قواعد وممنوعات صارمة للذكاء الاصطناعي (Strict Guardrails)

1. **الالتزام المطلق بالـ Tokens:** ممنوع كتابة أكواد ألوان صريحة `Color(0xFF...)` داخل صفحات الـ Widgets مباشرة. كل شيء يُستدعى عبر `Theme.of(context).colorScheme` أو `Theme.of(context).extension<MathTokens>()` أو `TenantThemeCubit`.
2. **عدم كسر الـ MVVM:** أي منطق إداري يمر عبر `Cubit` و `Repository`.
3. **لا أسرار في التطبيق:** ممنوع نهائياً كتابة `SUPABASE_SERVICE_ROLE_KEY` في الكود.
4. **دعم الاتجاهية (RTL/LTR):** كل الواجهات يجب أن تحافظ على العربية السليمة باستخدام `EdgeInsetsDirectional` و `AlignmentDirectional`.
5. **الحالات الأربع الإلزامية:** أي واجهة تجلب بيانات يجب أن تدعم (Loading / Empty / Error / Success).
