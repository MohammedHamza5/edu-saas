## ترتيب الاستخدام (أول مرة — ≈20 دقيقة)

1. فكّ ضغط الحزمة في مجلد جديد: `edu-saas/`.
2. في Antigravity: **New Project → Add Folder** واختر هذا المجلد.
3. أنشئ: مشروعي Supabase منفصلين (dev/prod) + حساب Bunny Stream + مشروع FCM، وطبق `0001_init.sql` على Dev، وانسخ `.env.example` إلى `.env` واملأه (لا ترفع `.env` إلى Git أبدًا).
4. **في كل دردشة جديدة:** الصق `01_AI_CONTEXT.md` ثم مهمتك الحالية من `07` عبر قالب `09`.
5. راجع Implementation Plan → علّق إن لزم → **Proceed** → بعد التنفيذ اطلب الأدلة (`flutter analyze` / `flutter test` / build) → قارن مع DoD ولا تنتقل للتالية قبل الاجتياز.
