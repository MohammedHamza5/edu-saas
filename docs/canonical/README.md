## البدء (أول مرة — ≈20 دقيقة)
1. فكّ ضغط الحزمة في مجلد `edu-saas/`.
2. Antigravity: **New Project → Add Folder** → اختر المجلد.
3. أنشئ الحسابات الخارجية: Supabase (dev/prod) + Bunny Stream + FCM.
4. طبق `supabase/migrations/0001_init.sql` على Supabase Dev.
5. انسخ `.env.example` إلى `.env` واملأه (لا ترفعه إلى Git).
6. **كل دردشة جديدة:** الصق `01_AI_CONTEXT.md` ثم مهمتك من `07_ROADMAP_TASKS.md` عبر قالب `09_DEFINITION_OF_DONE.md`.
