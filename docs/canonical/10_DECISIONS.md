## ثانيًا: القرارات المعمارية المقفولة 🔒 (من memory/decisions.md)

- **State Management = Cubit (flutter_bloc)** وليس Riverpod — معمارية غير مربوطة بالأداة: `UI → Cubit → Repository → DataSource`، ويمكن التبديل لاحقًا دون كسر الطبقات.
- **Backend = Supabase** (Auth + PostgreSQL/RLS + Storage + Edge Functions).
- **Video = Bunny Stream** — شبه نهائي: ينتظر اختبارًا عمليًا فعليًا قبل القفل 100%.
- **Push = FCM** (Web/Android/iOS) — توصيل فقط؛ الـDB هو مصدر الحقيقة.
- **Web Host = Cloudflare Pages**.
- **Secrets**: لا Service Role Key ولا أي Secret داخل Flutter/Git أبدًا — فقط Edge Function Secrets.
- **أدوار V1**: Teacher / Student / Parent فقط.
- **لا حذف نهائي للبيانات الأكاديمية** — status = archived/suspended.
- **بيئتان منفصلتان**: Development / Production.
- **لا PostgreSQL ENUM صارم** — text + تحقق على مستوى DB.

## ثالثًا: المنعيات النهائية 🔒 (من memory/constraints.md — المذكور هنا لا يُقترح ولا يُبنى أبدًا)

- لا Riverpod في V1 — القرار: Cubit فقط — 2026-09-06
- لا Drift / Offline DB كامل في V1 — تعقيد بلا حاجة؛ Online-First — 2026-09-06
- لا Dark Mode في V1 — يضاعف جهد الـQA؛ Tokens جاهزة لاحقًا — 2026-09-06
- لا Chat/Messaging بين المستخدمين — خارج النطاق قرار واعٍ — 2026-09-06
- لا Excel/PDF Export في V1 — مؤجل لـV1.1/V2 — 2026-09-06
- لا AI Risk Score / Predictions — خارج النطاق
- لا Custom Domain لكل Tenant في V1
- لا Staging Environment في V1
- لا Subscription/Billing (v1.16 فجوة موثّقة) بلا استرجاعه/إعادة كتابته
- لا "Anti-Cheat 100%" ولا "منع تصوير الشاشة" ولا "Unlimited Everything" في أي وعد
