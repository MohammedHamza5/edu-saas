# LOCALIZATION_RULES.md — قاعدة التعريب الفوري ومنع الديون اللغوية (إلزامية في كل دردشة)
> **تاريخ الاعتماد:** 2026-09-11 · **الحالة:** قاعدة دستورية غير قابلة للتفاوض (Non-Negotiable)

---

## 1. المبدأ الحاكم: "صفر نصوص ثابتة، صفر مفاتيح ناقصة" (Zero Hardcoded, Zero Untranslated)
في أي جلسة عمل أو دردشة، وأثناء بناء أي شاشة جديدة، ميزة، مكون (Widget)، نافذة منبثقة (Dialog)، إشعار، أو تعديل شاشة قائمة:
**يُمنع منعاً باتاً كتابة أي نص مباشر داخل الكود، ويُمنع تأجيل إضافة الترجمة العربية إلى وقت لاحق.**

---

## 2. بروتوكول التعريب الفوري المتزامن (Concurrent Localization Protocol)
عند إضافة أي نص جديد إلى التطبيق، يجب تنفيذ الخطوات الثلاث التالية معاً وفي نفس خطوة التعديل:

1. **إضافة المفتاح الإنجليزي في:**
   `lib/core/localization/arb/app_en.arb`
   مع إضافة وصف للمفتاح إذا كان يحتوي على متغيرات (Placeholders مثل `{name}`, `{count}`).

2. **إضافة المفتاح العربي المطابق فوراً في:**
   `lib/core/localization/arb/app_ar.arb`
   بلفظ عربي أكاديمي فصيح يناسب منصة SaaS لتعليم الرياضيات، مع مطابقة تامة لأسماء المتغيرات (`{name}`, `{count}`).

3. **توليد الكود البرمجي للترجمة فوراً:**
   ```bash
   flutter gen-l10n
   ```

4. **استدعاء النص داخل الـ Widget عبر الامتداد الرسمي المعتمد فقط:**
   ```dart
   import 'package:edu_saas/core/extensions/localized_context_extension.dart';

   // الاستخدام:
   Text(context.l10n.myNewKey)
   ```
   *(ممنوع استيراد `context_l10n.dart` أو غيره، وممنوع استخدام `AppLocalizations.of(context)!` مباشرة في الـ Widgets).*

---

## 3. شروط مطابقة المتغيرات (Placeholders)
- إذا احتوى النص الإنجليزي على متغير مثل `{count}`، **يجب** أن يحتوي النص العربي على نفس المتغير الحرفي `{count}` وبنفس الصيغة.
- لا يجوز تغيير اسم المتغير بين الإنجليزية والعربية إطلاقاً (عدم المطابقة يكسر `flutter gen-l10n`).

---

## 4. قائمة التحقق الإلزامية قبل تسليم أي مهمة (DoD Localization Check)
لا يجوز لأي وكيل ذكاء اصطناعي (Agent) إعلان اكتمال أي مهمة ("تم") إلا بعد استيفاء الشروط التالية:
1. **تطابق عدد المفاتيح:** عدد المفاتيح في `app_en.arb` = عدد المفاتيح في `app_ar.arb` بنسبة 100%.
2. **فحص عدم وجود نصوص غير مترجمة:** لا توجد أي رسالة تظهر باللغة الإنجليزية للمستخدم العربي أو العكس.
3. **توليد نظيف:** تشغيل `flutter gen-l10n` بنجاح دون أي خطأ في البنية.
4. **تحليل نظيف:** تشغيل `flutter analyze` دون أي خطأ أو تحذير متعلق بالنصوص.
