# Visual Identity & Hybrid Architecture Playbook (V1)
## الهوية البصرية والهندسة المعمارية الهجينة للمنصة

> تم اعتماد وتثبيت هذا التصميم رسمياً لتوحيد تجربة المستخدم البصرية مع أقصى راحة في القراءة والعمل الأكاديمي.

---

### 1. طبقات التصميم الهجين (The Modern Hybrid Architecture)

| الطبقة / الشاشات | النمط واللون الأساسي | المكونات وعناصر الهوية |
|---|---|---|
| **بوابات الدخول والـ Gateway**<br>(Splash / Login / Register / Pending / Suspended) | **أزرق كحلي رياضي ليلي عميق**<br>`Color(0xFF080C16)` إلى `Color(0xFF0F172A)` | • خلفية رياضية حية مع دالة جيبية $y = A \sin(kx - \omega t)$ وشبكة إحداثيات ونقاط تقاطع مشعة.<br>• بطاقة زجاجية بلورية عائمة (`BackdropFilter` blur 20 + حدود `#38BDF8`).<br>• نصوص بيضاء ناصعة وظلال مضيئة. |
| **أشرطة وهياكل التنقل (Shells)**<br>(Desktop Sidebar / Tablet Rail / Mobile Drawer) | **كحلي أكاديمي ليلي داكن فاخر**<br>`_sidebarBg = Color(0xFF0F172A)` | • تباين عالٍ بنصوص بيضاء ورمادية (`#CBD5E1`).<br>• عنصر تنقل نشط بإطار مشع بلون السماوي الرياضي (`#38BDF8`) وتوهج ناعم.<br>• ترويسة وتذييل ببطاقات بروفايل داكنة وأيقونات متناسقة. |
| **مساحة العمل ولوحة المحتوى (Canvas)**<br>(Dashboard / Lists / Feeds / Attendance / Exams) | **أرضية بيضاء أكاديمية دافئة**<br>`Color(0xFFF8FAFC)` | • شبكة إحداثيات رياضية فائقة الخفوت والنعومة (شفافية 3.2%) متحركة ببطء في الخلفية لمنع إجهاد العين أثناء قراءة الجداول والمعادلات.<br>• بطاقات محتوى ناصعة البياض بحدود نظيفة بدلاً من الظلال الثقيلة.<br>• `AcademicHeroBanner` كحلي بتدرج أنيق وأرقام بارزة ورموز رياضية خافتة في أعلى الصفحات الرئيسية. |

---

### 2. عناصر التفاعل ومؤشر الفأرة (Web Hover Interaction)
- **كل الأزرار، الكروت القابلة للنقر، عناصر الـ Sidebar، وعناصر الـ Choice Chips** مزودة صراحة بـ `mouseCursor: SystemMouseCursors.click`.
- عند مرور الماوس (Hover)، تظهر تأثيرات إضاءة خفيفة وانتقال سلس (`AnimatedContainer` duration 150ms).

---

### 3. الأمان والأداء الرياضي
- **AnimationController Tests Protection:** الخلفية المتحركة `AnimatedMathBackground` تفحص بيئة التشغيل تلقائياً (`Platform.environment['FLUTTER_TEST']`) وتثبت الأنيميشن عند `0.5` أثناء اختبارات الويدجت لمنع تجمد `pumpAndSettle()`.
- **Zero Raw Hex Colors:** كل الألوان مستمدة من التوكنات ومربوطة بنظام الهوية المعياري.
